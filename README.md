# OH! academy

Portal de estudos da **Escola de Vendas OH! Ótica**: trilha gamificada em 8 módulos para os vendedores das lojas OH! e parceiras.

## Situação

Fase 1: protótipo visual. Funciona só no aparelho de quem abre (o progresso fica salvo no navegador), com o Módulo 1 jogável, Biblioteca, Extras e um painel Admin com dados de exemplo.

Próximas fases:

1. Base: login individual, progresso, desbloqueio e XP salvos no Supabase (plano grátis).
2. Painel admin: subir materiais (PDF, áudio, vídeo do YouTube) e ver tempo e cliques de cada vendedor.
3. Conteúdo dos módulos 2 a 8, aos poucos, com piloto de 3 a 4 vendedores.
4. Lançamento, um módulo por semana.

## Publicação

Site estático no GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Arquivos

- `index.html`: o portal (HTML, CSS e JS num arquivo só).
- `manifest.webmanifest` e `icons/`: permitem instalar o portal no celular como app.
